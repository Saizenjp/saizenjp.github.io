`saizenjp.github.io` 리포지토리의 `/shizunoyado/` 폴더 → **https://saizenjp.github.io/shizunoyado/**

### ⚠ 지금은 검색에 안 잡힙니다 (일부러)

이 사이트는 **운영 시스템(`/ops/`)과 같은 호스트**에 얹혀 있습니다.
그 호스트의 루트 `robots.txt` 가 고객 개인정보를 다루는 내부 도구를 가리려고
**전체 색인을 막고 있어서**, 이 폴더도 함께 막힙니다.
`robots.txt` 는 **사이트 루트 것만 유효**하므로 이 폴더에 따로 두어도 소용이 없습니다
(그래서 생성물의 `robots.txt` 는 지웠습니다).

지금은 그게 오히려 낫습니다 — **자리표시자가 그대로 보이고 사진도 없는 상태**라
검색에 잡히면 안 됩니다. 내용을 다 채운 뒤에 열면 됩니다.

### 공개할 때 (둘 중 하나)

**A. 이 호스트에서 그대로 연다** — 루트 `robots.txt` 에 예외를 넣습니다.

    User-agent: *
    Disallow: /
    Allow: /shizunoyado/

⚠ 다만 주소가 `saizenjp.github.io/shizunoyado/` 로 남습니다. 명함·OTA·간판에 적기엔
회사 내부 도구 주소처럼 보이고, 내부 도구와 **같은 호스트**를 밖에 알리게 됩니다.

**B. 독자 도메인으로 옮긴다(권장)** — 별도 리포지토리 `shizunoyado` 를 만들어
이 폴더 내용을 올리고, Settings → Pages → Custom domain 에 도메인을 넣습니다.
리포지토리 루트에 도메인명 한 줄만 든 `CNAME` 파일을 두고,
`robots.txt` 를 `User-agent: *` / `Allow: /` 로 새로 만들면 됩니다.
사이트 주소를 전부 바꾸는 것을 잊지 마세요(`grep -rn "saizenjp.github.io" .`).
