사진 배치 도구

志津の宿 홈페이지 · 이 페이지는 검색에 안 잡히고, 사진은 어디에도 전송되지 않습니다
쓰는 법
  1. 사진을 이 화면 아무 데나 끌어다 놓으면 아래 「아직 안 정한 사진」에 쌓입니다. 한꺼번에 여러 장도 됩니다.
  2. 쌓인 사진을 자리로 끌어다 놓으면 그 자리에 들어갑니다. (사진을 한 번 누르고 자리를 누르셔도 됩니다.)
  3. 빈 자리를 눌러 파일을 직접 고르셔도 됩니다.
  4. 다 놓으셨으면 아래 [전부 내려받기] — 이름이 맞춰지고 크기도 줄어든 파일이 받아집니다.
  5. 받은 파일을 GitHub의 shizunoyado/images 폴더에 Add file → Upload files 로 끌어다 놓으면 사이트에 뜹니다.
본관 네 실(北條·合歓·山法師·志津)은 사진만으로 서로 구분할 수 없어 직접 놓아 주셔야 합니다. 별채 세 실(吉祥·瑞雲·馬酔木)도 마찬가지입니다. 객실 안에 탕이 보이면 별채입니다.
