📖 이 페이지 설명 · 계산 방식
현장에서 쓰는 물건의 수량을 등록하고, 들어오고 나가는 것을 기록하는 화면입니다. F&B(식자재·음료)와 객실(비품·린넨 등)을 같은 방식으로 관리합니다.

부서(F&B / 객실) 토글

위쪽 🍽 F&B / 🛏 객실 버튼으로 부서를 바꿉니다. 두 부서는 같은 시스템이지만 품목 목록은 서로 분리되어 보입니다. (랜딩에서 들어온 부서가 기본 선택됩니다.)

현재고 · 적정재고 · 부족 알림

  • 현재고 = 지금 보유한 수량. 입고·사용·실사로만 바뀝니다.
  • 적정재고 = "이 밑으로 떨어지면 채워야 한다"는 기준선.
  • 부족 판정: 현재고 ≤ 적정재고 이면 빨강 「부족」 뱃지 (적정재고를 0으로 두면 알림 안 함). 현재고 0이면 회색 「없음」.
  • 상단 요약의 ⚠ 부족 N = 그 부서에서 부족한 품목 수.

입고 / 사용 / 실사 — 계산 방식

  • ＋입고: 입력한 수량만큼 현재고를 더합니다 (현재고 + N).
  • －사용: 입력한 수량만큼 뺍니다 (현재고 − N).
  • 실사: 실제로 세어본 수량을 입력하면 그 값으로 맞춥니다. 차이(=실제−기존)는 실사조정으로 자동 기록됩니다.
  • 모든 변동은 최근 입출고 이력에 누가·언제·±수량·사유로 남습니다(되돌아보기·감사용).

권한 · 데이터

읽기는 로그인한 전원, 쓰기(추가·입출고·수정)는 주방(F&B)·객실 영역 담당자만 가능합니다. 저장 위치 — 품목=inv_items(현재고), 변동 기록=inv_txns(원장). ※POS 판매 시 자동 차감 연결은 다음 단계 예정(현재는 수동 입출고).
상단에서 Supabase 연결 후, 부서(F&B / 객실)를 선택하면 품목이 표시됩니다.
