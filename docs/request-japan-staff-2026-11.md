# 運営管理システム ご協力のお願い(現場ご担当者様へ)

株式会社SaiZen ／ 2026年11月

SaiZen の運営管理システムでは、お客様が空港に着いてから帰国されるまでの流れを一つのシステムでつなぎ、最後の精算まで締められるよう準備を進めています。
ホテル・フロント・レストラン・清掃・コース割当・精算はこのシステムで管理します。システムを使わない部署や外部の仕組み(経理・税理士、コース管理のカートナビ)には、**それぞれが今お使いの形に合わせたファイル**をシステムから出してお渡しします。

その形を正しく合わせるために、皆さまに確認していただきたいことを以下にまとめました。
分かる範囲でご記入いただき、分からない項目は「不明」で結構です。

---

## 1. いま出来ていること(参考)

| 場面 | システムでできること |
|---|---|
| 到着前 | 予約登録、部屋割り、ネームタグ・航空カバー・現地手配書・QRカードの印刷 |
| 到着 | 送迎の乗車確認、フロントのチェックイン、ロビーの歓迎表示 |
| 滞在中 | コース割当表・カート、夕食オーダー・厨房・POS、客室清掃、行事の申込、案内モニター |
| 帰国 | チェックアウト、お客様のQR請求書、送迎 |
| 精算 | 現場精算、日次締め、日報・週報・月報・年報、メリットツアー向け現地精算表 |

**今回追加したもの**:精算報告書の「月報」に **[経理提出用 Excel]** ボタンを作りました。
月末にこのファイルを経理(最終精算のご担当)へお渡しいただく想定です。日本語で作成され、次の内容が入ります。

- 表紙:月の主要数値と**検算**(日別合計と月合計、税率別合計と売上、入金と現金＋カード、未収の期首＋売上−入金と期末など)。合わない項目や、締めていない日、締めた後に数字が変わった日があれば「要確認」と表示されます。
- 日別:売上・消費税・入金・未収、締め時刻と担当、現金実査額と差額、締め後の変更内容
- 日別区分・税率別・区分/店舗別・未精算チェックアウト・B2B参考

金額はシステムが正確に集計します。ただし **「税務申告にそのまま使える形か」は金額の正しさとは別の問題**ですので、下の 2・3 をご確認ください。

## 4. コース管理(カートナビ・マーシャル Ai)についての確認

コース管理チームにお渡しするのは、カートナビ(マーシャル Ai)に登録する名簿です。
コース割当表の **[⬇ マーシャルAi 名簿]** ボタンから、テクノクラフト社の仕様(フロント系システム IF v6.0.2)に合わせた **プレーヤー名簿ファイル(CSV)** がすでに出せます。今まで IC Green で手入力していた名簿の代わりになります。
残りは、実際にカート側で読み込めるかの確認だけです。

| No. | 確認したいこと | ご記入欄 |
|---|---|---|
| 4-1 | 名簿ファイルを受け取って登録するご担当者(コース管理チームのどなたか) | |
| 4-2 | 毎日いつまでに必要ですか(例:前日17時/当日朝6時) | |
| 4-3 | マーシャル基地 PC の共有フォルダの場所(CSV を置く場所)・受け渡し方法(共有フォルダ/USB/メール) | |
| 4-4 | コース番号の設定(システムでは 阿蘇=0・祖母=1・久住=2 としています。違っていれば正しい番号) | |
| 4-5 | 実際に一度読み込みの試験をできる日時(CSV を置いて約30秒後にカートの画面に名前が出るかを確認) | |

## 5. お送りいただく方法

- 見本ファイルは**お客様の名前・連絡先・パスポート番号などを消したもの**で結構です。消すのが難しい場合はそのまま担当者(Min)へ直接お渡しください。外部には出しません。
- いただいた見本は形を合わせるためだけに使い、システムやインターネット上には保存しません。
- ご不明な点は Min までお問い合わせください。
