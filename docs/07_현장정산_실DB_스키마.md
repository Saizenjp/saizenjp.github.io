# 07 현장 정산 실DB 스키마 스냅샷 (2026-10-27)

## 4. 정산 테이블을 읽거나 쓰는 함수(2026-10-27)
| 함수 | 종류 | 비고 |
|---|---|---|
| `cart_sync_charge()` | 트리거(cart_bookings) secdef | 전기카트 사전신청 → charges(라운딩·golf), 무료일 제외(116). 세액 식 `round(gross/1.1)` → P1 에서 `tax_included()` 로 |
| `single_charge_sync_charge()` | 트리거 secdef | 싱글차지 → charges(59) |
| `dinner_addon_sync_charge()` | 트리거 secdef | 석식 추가·업그레이드 → charges(58) |
| `golf_add_charge(p_seq,p_desc,p_price,p_qty,p_link)` | RPC secdef | 코스 배정표 퀵 액션(9홀 추가) → 팀 open folio 찾거나 개설(146). 세액 식 `round(gross − gross/1.1)` |
| `walkin_open(…)` ×2 | RPC secdef | 워크인 접수(120·123) — folio 개설 |
| `guest_bill(p_token)` | RPC secdef **anon** | 손님 QR 청구서(73·90·92·121) |
| `settle_report(p_from,p_to)` | RPC secdef | 정산 일보·주보·월보·연보 집계(156) |
| `today_summary()` · `exec_stats(from,to)` | RPC secdef | 보드 요약(21·131) · 경영 통계(53·130·131·138) |

## 5. 세액 계산 지점(P0 통일 결과)
- JS: `SZCore.taxIncluded(gross, rate=10)` = `gross − round(gross/(1+rate/100))` — pos.html `taxOf`·settle.html `taxOf`·frontdesk.html 워크인 추가 항목이 전부 이 함수를 부른다.
- SQL: `tax_included(gross, rate)` 같은 식(157). `cart_sync_charge`·`golf_add_charge` 는 P1 에서 교체(지금 식과 정수 엔에서 같은 값).
- 실DB 대조(2026-10-27): charges 전 행의 저장 tax = 공통 식 값(불일치 0).

## 조회 방법
```sql
select table_name, column_name, data_type, is_nullable, column_default from information_schema.columns
 where table_schema='public' and table_name in ('folios','charges','payments','menu_items','settle_day_close') order by table_name, ordinal_position;
select conrelid::regclass, conname, pg_get_constraintdef(oid) from pg_constraint
 where conrelid in ('public.folios'::regclass,'public.charges'::regclass,'public.payments'::regclass) order by 1,2;
select tablename, policyname, cmd, qual, with_check from pg_policies where tablename in ('folios','charges','payments','menu_items','settle_day_close');
select tgrelid::regclass, tgname from pg_trigger where not tgisinternal and tgrelid in ('public.folios'::regclass,'public.charges'::regclass,'public.payments'::regclass);
select viewname, definition from pg_views where viewname in ('v_folio_balance','v_settlement_by_category');
```
