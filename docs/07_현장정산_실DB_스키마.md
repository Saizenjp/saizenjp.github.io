## 2. 뷰
- `v_folio_balance` — folio 별 청구합(税抜·税·봉사료)·税込 합계·입금합·잔액·건수 + rep_name/team_tag/group_code/member_name. **security_invoker=on**(39).
- `v_settlement_by_category` — session_ym × category 집계(行 amount/tax 합 — P1 부터 화면은 gross 만 쓴다). security_invoker=on.
- `v_settlement_by_rate`(158) — session_ym × tax_class × tax_rate: line_count·folio_count·gross_total·**tax_amount = Σ folio별 tax_included(folio 세율별 税込합, rate)**(계산서 단위 1회 버림)·charge_amount = gross − tax. security_invoker=on, anon revoke.

## 5. 세액 계산 지점(P0 통일 → P1 세율 구분·버림)
- JS: `SZCore.taxIncluded(gross, rate=10)` = **버림** `floor(gross × rate ÷ (100+rate))`(음수는 0 방향) — pos.html `taxOf`·settle.html `taxOf`·frontdesk.html 워크인 추가 항목·領収書(saizen-ops `rcTax`)가 전부 이 함수. `SZCore.taxByRate(lines)` = 계산서 단위·세율별 1회 버림 집계(화면 합계·御請求書·領収書·엑셀).
- SQL: `tax_included(gross, rate)` 같은 식(158 버림). 트리거 3종·`golf_add_charge`·`v_settlement_by_rate`·`settle_report`·`data_audit(tax_rate_check)` 가 이 함수.
- 기존 charges 행의 저장 amount·tax 는 재계산하지 않는다(참고값·불변) — 158 적용 뒤 새 행부터 버림. 표시·출력은 어차피 세율별 집계값.
- 158 드라이런(롤백, 2026-10-27): 10%×3(1,000)+8%(1,080·540)+非課税 200+不課税 500+RPC 1,239 → 뷰·보고서 by_rate 모두 10% 4,239/385 · 8% 1,620/120 · 非課税 200/0 · 不課税 500/0, 합계 6,559/505/6,054 = JS taxByRate 와 일치. golf_add_charge 1,239 → 세액 112(버림; 四捨五入이면 113). 조합 위반 insert 거부. anon secdef 15 유지.

## 조회 방법
```sql
select table_name, column_name, data_type, is_nullable, column_default from information_schema.columns
 where table_schema='public' and table_name in ('folios','charges','payments','menu_items','settle_day_close') order by table_name, ordinal_position;
select conrelid::regclass, conname, pg_get_constraintdef(oid) from pg_constraint
 where conrelid in ('public.folios'::regclass,'public.charges'::regclass,'public.payments'::regclass) order by 1,2;
select tablename, policyname, cmd, qual, with_check from pg_policies where tablename in ('folios','charges','payments','menu_items','settle_day_close');
select tgrelid::regclass, tgname from pg_trigger where not tgisinternal and tgrelid in ('public.folios'::regclass,'public.charges'::regclass,'public.payments'::regclass);
select viewname, definition from pg_views where viewname in ('v_folio_balance','v_settlement_by_category');
```
