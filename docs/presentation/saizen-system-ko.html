Architecture · 무엇으로 만들어졌나

설치할 게 없습니다 — 브라우저 + 클라우드

🖥 화면(웹)

  • GitHub Pages에 올린 웹 페이지 — 주소만 열면 됨
  • PC·노트북·태블릿·폰 아무 브라우저에서 동작
  • 화면은 한·일·영 3개 국어 전환

☁ 데이터(Supabase)

  • 모든 데이터가 클라우드 DB에 저장·공유
  • 여러 기기가 같은 데이터를 실시간으로 봄
  • 자동 백업(유료 플랜)

🔐 로그인·권한

  • 계정으로 로그인 후 사용(초대 발급)
  • 역할·담당 영역별로 보이는 화면 제한
  • 누가 언제 바꿨는지 변경 이력 기록

핵심: 별도 프로그램 설치·서버 운영이 없습니다. 인터넷과 브라우저만 있으면 현장 어느 기기에서든 같은 시스템에 접속해 함께 일합니다.

STEP 1 · 데이터 등록 (step1)

엑셀 업로드 한 번으로 그 달 전체 구성

무엇을 올리나

  • 예약리스트 — 팀(행사) 마스터
  • 일행별예약 — 개인 명단 + 개인별 항공정보(출·귀국편·시간)
  • 회원그룹코드 — 회원 참조표(초기화해도 유지)

자동으로 되는 것

  • 팀·개인·항공·회원 여부·등급 자동 정리
  • 그룹코드 자동 계산(회원=사전배정 / 일반=F풀)
  • 월 단위 동기화 — 그 달만 갱신, 다른 달 무영향

※ 파일에 없는 팀은 확인창을 거쳐 정리하고, 파일에 있는 팀은 배정을 보존한 채 갱신합니다.

개인 단위 자동배정 + 현장 규칙 내장

자동배정

  • 분할 체류(✂) · 조기 퇴실 · 객실 기간 폐쇄
  • 빈 방 클릭 배정 · 되돌리기 · 변경 이력

숙소: 골프텔 · 관내별장 · 소보/아소별장 · 돔하우스 · 쿠주힐즈 · 간지호텔 · 시즈노야도.

STEP 4 · 체크인 — 프론트데스크 (front) + 키택 (room)

프론트 = 바 = 레스토랑, 한 화면에서

프론트데스크

  • 날짜별 체크인 · 체크아웃 · 재실 + 오늘 석식·미수
  • 팀 클릭 → 운영 카드: 회원(등급)·조기퇴실·석식·키택·확인필요
  • 비고·메모 바로 입력 · 방배정/정산으로 딥링크

키택(키홀더 QR)

  • 체크인 때 팀 ↔ 키홀더 QR 바인딩
  • 키홀더 라벨(QR) 최초 1회 출력

STEP 5 · 주문 — POS + 팀 QR (pos)

손님 QR 한 번 → 정확한 팀 · 정확한 청구

① 주문 QR카드
인쇄물에서 팀별 발급
→
② 손님 촬영
체크인 때 폰으로 저장
→
③ POS 스캔
직원이 카메라로 읽음 → 팀 자동선택
→
④ 주문
팀공통 / 특정1인 / N분의1

왜 QR인가

  • 한국 손님 ↔ 일본 직원 언어 장벽을 건너뜀
  • 방번호 오인 없이 정확한 팀 특정
  • QR 없으면 태그코드·대표자 검색 → “이 팀 맞습니까?” 확인

주문 = 정산·주방으로

  • 주문 시 개인 분할이 가장 정확(누가 먹었는지 그때 기록)
  • 청구는 정산으로, 조리는 주방 티켓으로 자동
  • 손님 계산서 확인 화면(태블릿)에 실시간 표시

STEP 7·8 · 정산 (settle) / B2B 정산 (settle_merit)

두 개의 정산은 분리 — 혼동 금지

현장 정산(손님 청구)

  • 팀·개인 계산서(folio) — 개인 분할 묶음 표시

  • 메리트투어 ↔ SaiZen 선계약 금액
  • 숙박비(인원×박수×단가) + 송영비 자동 계산
  • 현장 추가요금과 별개 시스템
