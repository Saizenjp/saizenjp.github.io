# 리조트 사입(구매·조달) 관리 — 보통 어떻게 하는가

작성 2026-08-17 · 질문: "이런 리조트의 사입 관리는 각 부서가 하는지, 보통 회사들은 어떻게 관리하는지"
(일본 호텔·리조트 업계 일반 관행 + 우리 규모에 맞춘 권고. 우리 시스템 현황은 §5)

---

## 1. 세 가지 모델

| 모델 | 누가 발주하나 | 맞는 규모 | 장점 | 문제 |
|---|---|---|---|---|
| **① 부서 분산** | 각 부서가 직접 거래처에 발주 | 직원 20명 이하 | 빠르다. 현장이 필요한 걸 바로 산다 | 단가가 부서마다 다르다 · 중복 구매 · 누가 얼마 썼는지 사후에도 모름 · 사적 유용 위험 |
| **② 중앙 구매** | 부서는 **청구서(요청)** 만 올리고 **구매 담당이 발주** | 직원 100명 이상 | 단가 통제 · 예산 관리 · 부정 차단 | 현장이 느리다고 느낌 · 구매 담당이 병목 |
| **③ 하이브리드** | **신선식품은 부서 직발주**, 나머지는 중앙 | **직원 50~150명 = 우리 규모** | 속도와 통제를 같이 | 경계 규정이 필요(무엇을 부서가 살 수 있는지) |

**결론부터: 리조트는 거의 다 ③ 하이브리드다.** 채소·생선처럼 매일 시세가 바뀌고 당일 필요량이 정해지는 것은 주방이 직접 발주하지 않으면 운영이 안 되고, 어메니티·주류·자재·기계부품처럼 계획 구매가 가능한 것은 중앙에서 묶어 사야 단가가 나온다.

---

## 2. 일본 호텔·리조트의 표준 흐름

```
①発注(발주)  →  ②納品(납품)  →  ③検品(검품)  →  ④請求書照合(청구서 대조)  →  ⑤支払(지급)
   발주서 PO      납품서 보관     수량·품질 확인     발주=납품=청구 3장 대조     월마감 후 일괄
```

**핵심 원칙 — 3단계 분리(職務分離).**
**발주하는 사람 ≠ 검품하는 사람 ≠ 지급 승인하는 사람.** 한 사람이 둘 이상을 겸하면 유령 발주·수량 조작이 가능해진다. 소규모라 완전 분리가 어렵더라도 **최소한 검품과 지급 승인은 갈라야 한다.**

**같이 도는 관행들**

| 관행 | 내용 |
|---|---|
| **単価契約**(연간 단가계약) | 주거래처와 품목별 단가를 1년 단위로 못 박는다. 매번 견적 받지 않고 발주만. 성수기 가격 인상 방어. |
| **掛け取引**(월합계 외상) | 건별 결제가 아니라 월말 마감 → 다음 달 지급. 대신 **월마감 대조**가 필수. |
| **決裁権限規程**(결재 권한) | 금액대별 승인자를 규정으로 못 박는다. 예: 5만엔 미만 부서장 · 5~30만엔 총지배인 · 30만엔 이상 대표. |
| **棚卸**(재고조사) | 월 1회 실사. F&B는 **원가율(食材原価率)** 산출에 필수 — 이게 없으면 이익이 어디서 새는지 알 수 없다. |
| **主要仕入先 집중** | 거래처를 일부러 3~5곳으로 줄여 물량을 몰아 단가를 낮춘다(대신 대체처 1곳은 항상 확보). |
| **消化仕入**(위탁 매입) | 골프샵 판매 상품에 흔함 — 팔린 만큼만 매입 계상. 재고 위험을 거래처가 진다. |

## 3. 부서별 성격이 다르다

| 부서 | 무엇을 사나 | 발주 주기 | 누가 | 관리 지표 |
|---|---|---|---|---|
| **식음(F&B)** | 채소·생선·정육(신선) / 주류·건화물·냉동(저장) | 신선 **매일** · 저장 주 1회 | 신선=주방장 직발주 · 저장=중앙 | **원가율 25~35%**, 폐기율 |
| **객실(HK)** | 어메니티·린넨·청소용품 | 월 1회 대량 | 중앙 | 인박당 원가(¥800~1,200) |
| **골프 코스** | 잔디 종자·비료·농약·기계 부품·연료 | **연간 계획** + 월 보충 | 코스 관리자 계획 → 중앙 발주 | 홀당 연 관리비 |
| **골프샵** | 판매용 상품(볼·글러브·의류) | 시즌 전 · 소진 시 | 중앙(또는 위탁 매입) | 상품 회전율·소진율 |
| **시설·설비** | 수선 자재·소모 부품 | 수시 | 시설 담당 | **수선비 vs 자본적 지출** 구분 |
| **송영** | 연료·타이어·정비 | 수시 | 시설/총무 | km당 원가 |

**주의할 두 가지 회계 구분**
- **재고자산 vs 즉시 비용** — 창고에 쌓아두고 쓰는 것(주류·어메니티)은 재고로 잡고 쓴 만큼 비용, 당일 소진되는 신선식품은 매입 즉시 비용으로 처리하는 게 실무상 일반적이다.
- **수선비 vs 자산** — 원상 회복은 비용, 성능·수명을 늘리면 자산(감가상각). 세무상 다툼이 잦은 지점이다.

## 4. 왜 이게 이익에 직결되는가 (우리 숫자)

`docs/profitability-estimate.md` 기준 연간 구매성 비용은 이렇다.

| 항목 | 연간 | 매출 대비 |
|---|---:|---:|
| 식음 원가 | 1.16억엔 | 13.8% |
| 코스 관리 자재·위탁 | 0.84억엔 | 10.0% |
| 객실 소모품·린넨 | 0.55억엔 | 6.5% |
| 송영 연료·정비 | 0.09억엔 | 1.1% |
| **합계** | **2.64억엔** | **31.4%** |

**현재 영업이익은 0.45억엔이다. 구매 비용이 2.64억엔이므로, 사입을 5%만 절감하면 0.13억엔 — 영업이익의 29%가 늘어난다.** 인건비를 건드리는 것보다, 송객을 늘리는 것보다 통제 가능성이 높은 영역이다. 반대로 **관리가 없으면 5%가 조용히 새어 나가도 아무도 모른다.**

## 5. 우리 시스템 현황과 빈 칸

지금 있는 것 (`ops/hub/inventory.html` · SQL 36):

| 테이블 | 컬럼 | 하는 일 |
|---|---|---|
| `inv_items` | dept, category, name, unit, location, **par_level**, current_qty | 품목 마스터 + 적정재고 |
| `inv_txns` | item_id, delta, reason, qty_after, created_by | 입고/사용/실사 원장 |

**즉 「재고가 몇 개 있나」는 되지만, 「얼마에 누구에게 사서 얼마를 지급했나」가 없다.** 구매 관리의 핵심(금액·거래처·발주·대조)이 통째로 비어 있다.

| 빠진 것 | 왜 필요한가 |
|---|---|
| **거래처(仕入先)** | 단가 비교·집중 구매·월마감 대조의 기준 |
| **단가(unit_cost)·단가계약** | 금액이 없으면 원가율을 못 낸다. 지금 재고는 수량만 센다 |
| **발주(PO)** | 부서 청구 → 승인 → 발주 흐름. 누가 승인했는지 남는다 |
| **입고 검품** | 발주 수량 ≠ 납품 수량을 잡아내는 지점 |
| **청구서 대조·월마감** | 거래처 청구서와 우리 입고 기록의 차이 확인(과청구 방지) |
| **부서별 예산** | 월 한도 대비 소진율. 초과 시 승인 상향 |

## 6. 권고 — 우리 규모(80명)에서 현실적인 형태

**조직**
- 전임 구매 담당을 두기엔 규모가 작다 → **총무·경리 1명이 구매를 겸임**하고, **부서는 청구만** 올리는 형태가 적정하다.
- 예외로 **주방 신선식품은 주방장 직발주 허용**(당일 시세·필요량). 단 **월 한도**를 정하고, 사후에 단가 이력을 본다.
- 최소 통제선: **검품은 발주한 사람이 하지 않는다**(프론트 또는 총무가 확인 서명). 지급 승인은 대표.

**결재 권한 예시** (금액은 우리 규모에 맞춘 안)

| 금액 | 승인 |
|---|---|
| 3만엔 미만 | 부서장 |
| 3~20만엔 | 총지배인(또는 관리담당) |
| 20만엔 이상 · 연간 계약 | 대표 |

**시스템 도입은 단계로** — 한 번에 다 만들면 현장이 안 쓴다.

| 단계 | 무엇 | 효과 |
|---|---|---|
| **1** | `inv_items`에 **단가·거래처** 추가 + `inv_txns` 입고에 단가·금액 기록 | 오늘부터 **원가율·부서별 지출액**이 나온다. 화면 변경 최소 |
| **2** | **거래처 마스터 + 월별 지출 집계** 화면 | 어디에 얼마 쓰는지, 단가가 오르는지 보인다 |
| **3** | **발주(PO) → 입고 검품** 흐름 | 유령 발주·과납품 차단. 승인 이력 |
| **4** | **청구서 대조 · 월마감** | 과청구 적발. 경리 마감 시간 단축 |
| **5** | 부서 예산·소진율 알림 | 초과 전에 제어 |

1단계만 해도 지금 완전히 안 보이는 **매출의 31%가 어디로 가는지**가 숫자로 잡힌다. 우리 시스템은 이미 `inv_txns` 원장 구조가 있어서, **단가 컬럼 하나와 거래처 하나만 붙이면 바로 원가율이 나온다** — 여기서 시작하는 것을 권한다.
