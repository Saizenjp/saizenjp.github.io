# 운영 관리 시스템 협조 요청(현장 담당자께) — 한국어 번역본

주식회사 SaiZen ／ 2026년 11월

> 이 문서는 `request-japan-staff-2026-11.md`(일본어 원문)의 한국어 번역본입니다. 현장에 전달하는 것은 일본어 원문이고, 번역본은 내용 확인용입니다. 일본어 고유명(경리 제출용 Excel 등)은 화면 표기를 괄호에 함께 적었습니다.

SaiZen 운영 관리 시스템은 손님이 공항에 도착한 때부터 귀국할 때까지의 흐름을 하나의 시스템으로 잇고, 마지막 정산까지 마감할 수 있도록 준비하고 있습니다.
호텔·프런트·레스토랑·청소·코스 배정·정산은 이 시스템으로 관리합니다. 시스템을 쓰지 않는 부서나 외부 시스템(경리·세무사, 코스 관리의 카트 네비)에는 **각각 지금 쓰고 있는 형식에 맞춘 파일**을 시스템에서 만들어 전달합니다.

그 형식을 정확히 맞추기 위해, 확인해 주셨으면 하는 내용을 아래에 정리했습니다.
아는 범위에서 적어 주시고, 모르는 항목은 「모름(不明)」으로 적어 주셔도 됩니다.

## 1. 지금 되는 것(참고)

| 단계 | 시스템에서 할 수 있는 일 |
|---|---|
| 도착 전 | 예약 등록, 방배정, 네임택·항공커버·현지 수배서·QR 카드 인쇄 |
| 도착 | 송영 승차 확인, 프런트 체크인, 로비 환영 표시 |
| 체류 중 | 코스 배정표·카트, 석식 오더·주방·POS, 객실 청소, 행사 신청, 안내 모니터 |
| 귀국 | 체크아웃, 손님 QR 청구서, 송영 |
| 정산 | 현장 정산, 일 마감, 일보·주보·월보·연보, 메리트투어용 현지 정산표 |

**이번에 추가한 것**: 정산 보고서의 「월보」에 **[경리 제출용 Excel(経理提出用 Excel)]** 버튼을 만들었습니다.
월말에 이 파일을 경리(최종 정산 담당)에게 넘기는 것을 생각하고 있습니다. 일본어로 만들어지며 다음 내용이 들어갑니다.

- 표지: 그 달의 주요 숫자와 **검산**(일별 합계와 월 합계, 세율별 합계와 매출, 입금과 현금+카드, 미수의 기초+매출−입금과 기말 등). 맞지 않는 항목이나 마감하지 않은 날, 마감한 뒤 숫자가 바뀐 날이 있으면 「요확인(要確認)」으로 표시됩니다.
- 일별: 매출·소비세·입금·미수, 마감 시각과 담당자, 현금 실사액과 차액, 마감 뒤 바뀐 내용
- 일별 구분·세율별·구분/매장별·미정산 체크아웃·B2B 참고

금액은 시스템이 정확히 집계합니다. 다만 **「세무 신고에 그대로 쓸 수 있는 형식인가」는 금액이 맞는지와는 별개의 문제**이므로, 아래 2·3을 확인해 주십시오.

## 2. 경리·정산에 대한 확인

| No. | 확인하고 싶은 것 | 기입란 |
|---|---|---|
| 2-1 | 월 정산 서류를 최종적으로 받는 분은 누구입니까(사내 경리/세무사 사무소/기타) | |
| 2-2 | 회계 소프트를 쓰고 있습니까. 쓰고 있다면 이름(야요이(弥生)·freee·머니포워드 등) | |
| 2-3 | 회계 소프트로 가져오기 위한 정해진 형식(CSV 열 순서 등)이 있습니까. 있으면 견본 파일 1개 | |

| 2-5 | 현금 실사는 누가, 언제 합니까(일 마감의 「현금 실사액」을 입력하는 분) | |
| 2-6 | 지금 종이나 별도 Excel 로 만들고 있는 정산·일보 서류가 있으면 그 견본(개인정보는 지운 것이면 됩니다) | |

## 4. 코스 관리(카트 네비·마샬 Ai)에 대한 확인

코스 관리팀에 전달하는 것은 카트 네비(마샬 Ai)에 등록하는 명단입니다.
코스 배정표의 **[⬇ 마샬 Ai 명단(マーシャルAi 名簿)]** 버튼으로 테크노크래프트사 사양(프런트계 시스템 IF v6.0.2)에 맞춘 **플레이어 명단 파일(CSV)** 을 이미 만들 수 있습니다. 지금까지 IC Green 에서 손으로 넣던 명단을 대신합니다.
남은 것은 실제로 카트 쪽에서 읽히는지 확인하는 것뿐입니다.

| No. | 확인하고 싶은 것 | 기입란 |
|---|---|---|
| 4-1 | 명단 파일을 받아 등록하는 담당자(코스 관리팀의 어느 분) | |
| 4-2 | 매일 언제까지 필요합니까(예: 전날 17시/당일 아침 6시) | |
| 4-3 | 마샬 기지 PC 의 공유 폴더 위치(CSV 를 두는 곳)·전달 방법(공유 폴더/USB/메일) | |
| 4-4 | 코스 번호 설정(시스템에서는 아소=0·소보=1·쿠주=2 로 하고 있습니다. 다르면 올바른 번호) | |
| 4-5 | 실제로 한 번 읽기 시험을 할 수 있는 일시(CSV 를 두고 약 30초 뒤 카트 화면에 이름이 뜨는지 확인) | |

## 5. 보내 주시는 방법

- 견본 파일은 **손님 이름·연락처·여권 번호 등을 지운 것**이면 됩니다. 지우기 어려우면 그대로 담당자(Min)에게 직접 전달해 주십시오. 외부에는 내보내지 않습니다.
- 받은 견본은 형식을 맞추는 데에만 쓰고, 시스템이나 인터넷에는 저장하지 않습니다.
- 모르는 점은 Min 에게 문의해 주십시오.
