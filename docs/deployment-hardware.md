# SaiZen Yamanami — 현장 장비 배치 가이드 (v2)

> 웹 기반(GitHub Pages + Supabase) — 앱 설치 없이 브라우저만 있으면 동작. 고사양 불필요, **안정성·내구성·인터넷 회선**에 예산 집중.
> 가격은 **일본 조달 참고가(2024–25, 세금·배송 별도, 변동)**. 중상위 사양 기준.
> **v2 반영**: ① 프론트(로비)는 **조회·정산** 중심(방배정 *작업* 아님) → 표준 모니터. ② 방배정 *작업*(room.html)은 **백오피스/기획석** → 광폭 QHD. ③ 손님 정산은 **2~3 레인** → 레인마다 직원 단말 + 손님 표시.
> ⚠ **확정 필요** 항목은 추가 확인 후 v3 반영.

---

## 0. 전제 · 원칙
- **인터넷 필수** → 끊기면 라이브 조작 일시 정지(데이터는 안전). **회선 이중화 1순위.**
- 화면에 **고객 PII**(프론트·정산) → **프라이버시 필터** 필요.
- 주방 KDS는 열·물·기름 → 터치모니터 + 보호.
- 손님 표시 태블릿은 **읽기전용·키오스크 + 도난방지**.

## 9. 확정 필요 (v3 반영)
1. **로비 정산 레인 = 2 / 3 중 확정**(직원 PC 방식 vs 태블릿+공용프린터 방식).
2. **POS 매장 수**(레스토랑/연회·골프샵·매점 외 추가?).
3. **바 KDS** 별도 vs 주방 겸용.
4. **WiFi 커버 건물 수·거리** → AP 대수·메시 필요 여부.
5. **위성 리셉션**(간지·시즈노야도·쿠주힐즈 자체 체크인 데스크) 필요 여부 — 있으면 §3 레인을 그 건물에도.
6. iPad vs Galaxy Tab 통일.
7. 예산 상·하한.

*문서 버전: v2 · 프론트=조회/정산, 방배정=백오피스, 정산 2~3레인 반영.*
