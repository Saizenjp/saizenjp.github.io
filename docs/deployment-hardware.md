# SaiZen Yamanami — 현장 장비 배치 가이드 (v1 초안)

> 이 시스템은 **웹 기반**(GitHub Pages + Supabase)이라 앱 설치 없이 **브라우저(Chrome/Edge/Safari)** 만 있으면 동작합니다.
> 따라서 고사양은 불필요하고, **안정성·내구성·인터넷 회선**에 예산을 쓰는 것이 효율적입니다.
> 가격은 **일본 조달 기준 참고가(2024–25, 세금·배송 별도, 변동)** 입니다. 중상위 사양 기준으로 잡았습니다.
> ⚠ **확정 필요** 표시 항목은 Min 확인 후 v2에서 수량·모델을 조정합니다.

---

## 0. 전제 · 원칙
- **인터넷(Supabase) 필수** → 끊기면 라이브 조작 일시 정지(데이터는 안전). **회선 이중화가 1순위.**
- 화면에 **고객 개인정보(PII)** 가 표시됨(프론트·정산) → **프라이버시 필터** 필요.
- 주방 KDS는 **열·물·기름** 환경 → 터치모니터 + 보호.
- 손님 확인용 태블릿은 **읽기전용·키오스크 모드 + 도난방지**.

## 10. 확정 필요 (v2에서 반영)
1. **건물별 자체 체크인 데스크 유무** → 위성 리셉션 대수 확정(간지·시즈노야도·쿠주힐즈).
2. **POS 매장 수**(프론트매점·레스토랑/연회·골프샵 외 추가?).
3. **손님 확인 화면** 설치 위치 수(레지스터 몇 곳?).
4. **바 KDS** 별도 필요 여부(주방과 겸용 가능?).
5. **WiFi 커버 건물 수·거리** → AP 대수·메시 필요 여부.
6. iOS(iPad) vs Android(Galaxy Tab) 통일 선호.
7. 예산 상·하한(프리미엄 모니터/라우터 채택 여부).
